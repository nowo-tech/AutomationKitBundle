# Automation Kit Bundle

Automation for Symfony: event-triggered rules with conditions, delays and actions, and sequences that enrol records
in timed steps. Triggers, conditions and actions are registered by service tag; runs go through Messenger with
idempotency, loop guards, rate limits, a kill switch and a run log.

Status: contract first (owner decision Q-254-7, 2026-11-23). No code yet. Contract: `docs/CONTRACT.md` in the open
pull request.
